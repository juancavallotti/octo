octopaas is the command line for an Octo platform's public API.

It edits integrations and their files, freezes them into versions, deploys those versions and follows what they log, all as you: your roles decide what it may do, and every change is attributed to you.

Sign in once with `octopaas auth login`. For automation, set OCTOPAAS_URL and OCTOPAAS_KEY instead and no sign-in or config file is needed.

For installing it, signing in and using it in CI/CD, see [the octopaas guide](/platform/octopaas).

| Flag | What it does | Default |
| --- | --- | --- |
| `--plain` | no colours, animations or art, even in a terminal |  |
| `--url` | the API to talk to, overriding the profile (default: $OCTOPAAS_URL) |  |
